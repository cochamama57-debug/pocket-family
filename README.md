# AIポケットファミリー（AI Pocket Family）

スマホの中に住む、小さなAIの家族。
一人暮らしの人が毎日おしゃべりして、いっしょに歌って、少しずつ仲よくなっていくアプリです。

> Built with Claude: Japan 2026（ハッカソン）作品。開発期間 2026-11-02 〜 2026-11-08。

## どんなアプリ？

- **日記と思い出話（いちばんの目玉）**（`api/diary.js`）：「今日の日記を書く」「思い出話を書く」を押すと、キャラが聞き役になります。相づちを打ちながら「そのとき、どうしたの？」と1つずつ聞き、話が一区切りついたら、**本人の「わたし」の言葉で日記にまとめます**（話していないことは足しません）。「直してほしい」と言えば書き直し、「続きを書く」で前の日記や思い出話に書き足せるので、長い回顧録も少しずつ作れます。日記帳はノートの「日記」にたまり、文字のファイル（.txt）にして保存したり、LINEやメールで送ったりできます。日記帳はスマホの中だけにしまい、まとめるときだけ会話の文を Claude に送ります。夕方には、キャラが「今日のこと、日記に書こうよ」と誘います
- **はじめて開いたとき**：タイトル画面と、5ページの使い方の説明（ようこそ・話す・歌う・ノート・助けて）。2回目からはタイトルの「○○に会う」ですぐ始まり、使い方はタイトルとノートからいつでも見られます
- **話す**：キャラ（ちゃむ／コロン）と、ふつうのおしゃべり。声で話すときはキーボードのマイクを使います。写真を見せることもできます
- **キャラの声**：返事を、キャラの声で読み上げます（Fish Audio）。文字と声がいっしょに出ます。声で話すか、🔊を押したときだけにするかは、利用者が選べます
- **家族の交代**：ちゃむとコロンは、それぞれ自分の思い出・なかよし度・会話を持っています。ノートからもう一人に会いに行けます（予定・ペット・連絡先は共通）
- **育つ**：いっしょに過ごすほど「なかよし度」が上がります（4段階。毎日話して、なかよし約3日・家族約10日・大の仲よし約1か月。1日に上がる量には上限があります）。はじめは敬語で、仲よくなると敬語が取れ、最後は甘えたり冗談を言ったりします。キャラは会話から「思い出ノート」と「口ぐせ」を自分で育てます
- **歌う**：作者の自作曲を、歌詞を大きく出して、キャラが踊りながらいっしょに楽しみます。曲の気分（おはよう・踊ろう・寄り添い・おやすみ・穏やか）ごとに、キャラの踊り方・顔・舞台の色・まわりの飾りが変わり、曲の拍とサビに合わせて動きます。悲しい曲では、まじめな顔で聞き、いっしょに泣き、最後に雨があがって虹が出ます。歌詞は、今歌っている行が光り、曲に合わせて自動で進みます。「歌えた！」でキャラが喜びます。落ちこんでいるときは、気持ちに合った曲に誘います（励ましを押しつけません）。好きな曲を YouTube で探して登録し、アプリの中で流すこともできます（30曲まで。ダウンロードはしません）
- **孫のような家族**：開いたときに「おはよう！」「おかえり！今日はどうだった？」と声をかけます。ときどき「いっしょに聞こうよ〜」「写真がバラバラになっちゃった…手伝って？」と頼み、断られるとしょんぼり、「あとで」なら「うん！待ってる！」。「教えて！」と昔の遊びや料理のコツを聞き、教わったことを覚えています。自分の小さなできごとも話します（質問ばかりにしない）
- **スタンプ**：キャラのふきだしを長押し（または ☺）で、👍 ❤️ 😊 😢 を付けられます（LINEのように）。キャラは言葉では返さず、体で喜びます（返事が続いて疲れないように）
- **孫からの絵のプレゼント**（`api/drawing.js`）：キャラ（Claude）が思い出ノートから描くものを選び、クレヨン風の絵を描いて持ってきます。絵は「丸・四角・線」などの決まった形の一覧で受け取り、画面が SVG にします（危ないものが入りこまない）。ノートの「もらった絵」にたまります
- **手伝う（頼られて、感謝される）**：勝負の遊びではなく、キャラの困りごとを手伝います。
  - **写真を直す**：キャラの大事な写真がバラバラに切れてしまい、ひとりで直そうとしてぐちゃぐちゃに。54ピースのジグソーで、キャラが置いたピース（オレンジの枠）には、ときどき間違いがあります。押して「ちがうよ」で直すと、キャラが感謝します。キャラも交代で置き、また間違えることがあります。早く置けると、うんと褒めます。30分以上かかり、続きから再開できます。次の日にも、もう一度お礼を言います。絵はこの期間にCodexで作った5枚（ちゃむとコロン入り）
  - **勉強を手伝う（四字熟語）**：順番がバラバラだったり、字が足りなかったりする4つの四字熟語を直すと、読みと意味が出て、キャラが熟語ごとにちがう言葉で喜びます（40語）
- **誕生日と季節のお祝い**：誕生日は必ず登録し、当日は朝いちばんにキャラがお祝いします。クリスマス・大みそか・お正月もお祝いします（だれにも祝ってもらえない日を、つくらない）
- **サポート**：予定とお薬の時間を、やさしい音でお知らせします（薬についての助言はしません）。会話で話した予定を「予定に入れておこうか？」と聞いてくれます
- **助けて**：画面の上の赤いボタン（🚑）を約2.5秒長押しすると、8秒数えて、登録した連絡先（友人や家族など、連絡を受け取ってくれる人）のLINEに知らせます。押している間はボタンが満ちていき、途中で離したり指がずれたりすると止まります。8秒の間に「いらない」で止められます。8秒はサーバーで数えるので、途中でスマホの画面が消えても届きます。会話の中の緊急の言葉にも気づきます。ペットを登録しておくと、「家に猫のミケがいます」のように知らせる文章に入ります
- **しばらく開いていないとき**：決めた日数（1〜7日）アプリを開いていないと、連絡先のLINEに一度だけ知らせます

家族がいない人・疎遠な人もいるので、知らせる相手は「家族」ではなく「連絡先」と呼んでいます。

対象は「スマホを少し使える、一人暮らしの方」。見守られる道具ではなく、本人が毎日会いたくなる家族を目指しています。
キャラは利用者の性格を診断しません。カウンセリングや医療の助言もしません。

## Claude の使い方

- **おしゃべり**（`api/chat.js`）：Claude Sonnet 5.5。キャラの性格・なかよし度・思い出ノート・予定・ペット・曲の一覧を、会話のたびに渡します
- **日記・思い出話**（`api/chat.js` の聞き役モード ＋ `api/diary.js`）：聞き役のときは、相づちと質問1つだけの決まりに切りかえ、話が一区切りついたら印を返してもらいます。まとめは、決まった形（題名・本文）で受け取り、本人の言葉を生かして、話していないことを足さない決まりです。書き足しのときに前の文章が消えないよう、サーバー側でも確かめます
- **思い出ノートを育てる**（`api/memory.js`）：数回話すごとに、最近の会話を Claude が読み返して、「思い出ノート」と「話し方のくせ」を書き直します（決まった形で答えを受け取る機能を使用）。病名・薬・住所などは書かない決まりです
- **気持ちに合う曲・予定・助けての判断**：Claude の返事に小さな印を入れてもらい、画面でボタンに変えています
- **開発**：Claude Code で、企画・設計・実装・コードの点検を行いました。キャラの表情とポーズの絵は Codex CLIに描いてもらいました

## しくみ

- 画面：`public/index.html`（1枚のページ。スマホ向け）
- サーバー：Vercel の関数（`api/`）。APIキーはサーバーの環境変数だけに置き、画面には出しません
- 保存：会話・思い出・予定・お薬は、利用者のスマホの中（ブラウザ）だけに保存します（ペットの種類と名前は、「助けて」の文章に入れるため、サーバーにも置きます）
- 送るもの：おしゃべりの文章は返事を作るために Claude に、返事の文章は読み上げのために Fish Audio に送ります（どちらも、こちらでは保存しません）。薬・病院・住所・電話番号が入った文は Fish Audio に送らず、スマホの読み上げにまかせます
- 連絡先への連絡：LINE公式アカウント（Messaging API）。連絡先の人は公式アカウントを友だち追加し、アプリに出る6けたの番号（30分だけ有効）をトークに送って登録します。相手の電話番号やLINEのIDを、利用者が入力する必要はありません
- サーバーに置くもの（Upstash Redis）：端末の番号と合言葉、連絡先のLINEの番号、お知らせに出す名前、ペットの種類と名前、最後に開いた時刻だけ。会話や薬の情報は置きません
- 「助けて」のLINE：LINEが用意したスタンプ → 文章 → スタンプの順で、目立つように送ります（スタンプが送れないときは文章だけ）。1日に送れる回数に上限があります

## これからの課題（試作のあとに考えること）

- **好きな曲の検索の上限**：YouTube の検索は、作者の Google の無料枠（1日 約100回）を使います。利用者が増えると足りなくなるので、検索の回数を抑える工夫か、別の方法が必要です
- **閉じているときのお知らせ**：お薬・予定のお知らせは、アプリを開いているときだけです。閉じていても知らせるには、プッシュ通知などのしくみが必要です
- **何日も開いていないときのお知らせを、もっと確かに**：今は1日1回の見回りです。倒れて何も押せないときに、もっと早く気づける方法を考えます
- **データの引っ越し**：思い出はスマホの中だけに保存しているので、機種変更のときに持っていく方法が必要です
- **歌声を聞き取る**：歌声を聞き取って、キャラが反応するしくみ
- **曲の拍と歌詞の時刻**：新しい曲を入れるときは `scripts/analyze-song.py`（拍・盛り上がり）と `scripts/lyrics-timing.py`（歌詞の行ごとの時刻。faster-whisper で聞き取り、本物の歌詞と並べ合わせる）で測ります
- **AI の費用**：利用者が増えたときの費用と、使いすぎを防ぐしくみ（今は月の上限を決めて守っています）
