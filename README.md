# AIポケットファミリー（AI Pocket Family）

スマホの中に住む、小さなAIの家族。
一人暮らしの人が毎日おしゃべりして、いっしょに歌って、少しずつ仲よくなっていくアプリです。

> Built with Claude: Japan 2026（ハッカソン）作品。開発期間 2026-11-02 〜 2026-11-08。

## どんなアプリ？

- **話す**：キャラ（ちゃむ／コロン）と、ふつうのおしゃべり。声で話すときはキーボードのマイクを使います。写真を見せることもできます
- **育つ**：いっしょに過ごすほど「なかよし度」が上がり、話し方や性格が変わっていきます。キャラは会話から「思い出ノート」と「口ぐせ」を自分で育てます
- **歌う**：作者の自作曲を、歌詞を大きく出して、キャラが踊りながらいっしょに楽しみます。「歌えた！」でキャラが喜びます。落ちこんでいるときは、気持ちに合った曲に誘います（励ましを押しつけません）
- **サポート**：予定とお薬の時間を、やさしい音でお知らせします（薬についての助言はしません）。会話で話した予定を「予定に入れておこうか？」と聞いてくれます
- **助けて**：小さなボタンを長押しすると、8秒数えて、家族のLINEに知らせます（「いらない」で止められます）。8秒はサーバーで数えるので、途中でスマホの画面が消えても届きます。会話の中の緊急の言葉にも気づきます。ペットを登録しておくと、「家に猫のミケがいます」のように知らせる文章に入ります
- **しばらく開いていないとき**：決めた日数（1〜7日）アプリを開いていないと、家族のLINEに一度だけ知らせます

対象は「スマホを少し使える、一人暮らしの方」。見守られる道具ではなく、本人が毎日会いたくなる家族を目指しています。
キャラは利用者の性格を診断しません。カウンセリングや医療の助言もしません。

## Claude の使い方

- **おしゃべり**（`api/chat.js`）：Claude Sonnet 5.5。キャラの性格・なかよし度・思い出ノート・予定・ペット・曲の一覧を、会話のたびに渡します
- **思い出ノートを育てる**（`api/memory.js`）：数回話すごとに、最近の会話を Claude が読み返して、「思い出ノート」と「話し方のくせ」を書き直します（決まった形で答えを受け取る機能を使用）。病名・薬・住所などは書かない決まりです
- **気持ちに合う曲・予定・助けての判断**：Claude の返事に小さな印を入れてもらい、画面でボタンに変えています
- **開発**：Claude Code で、企画・設計・実装・コードの点検を行いました。キャラの表情とポーズの絵は Codex CLIに描いてもらいました

## しくみ

- 画面：`public/index.html`（1枚のページ。スマホ向け）
- サーバー：Vercel の関数（`api/`）。APIキーはサーバーの環境変数だけに置き、画面には出しません
- 保存：会話・思い出・予定・お薬・ペットは、利用者のスマホの中（ブラウザ）だけに保存します
- 家族への連絡：LINE公式アカウント（Messaging API）。家族は公式アカウントを友だち追加し、アプリに出る6けたの番号（30分だけ有効）をトークに送って登録します。家族の電話番号やLINEのIDを、利用者が入力する必要はありません
- サーバーに置くもの（Upstash Redis）：端末の番号と合言葉、家族のLINEの番号、お知らせに出す名前、ペットの種類と名前、最後に開いた時刻だけ。会話や薬の情報は置きません
- 「助けて」のLINE：LINEが用意したスタンプ → 文章 → スタンプの順で、目立つように送ります（スタンプが送れないときは文章だけ）。1日に送れる回数に上限があります

## これからの課題（試作のあとに考えること）

- **好きな曲の検索の上限**：YouTube の検索は、作者の Google の無料枠（1日 約100回）を使います。利用者が増えると足りなくなるので、検索の回数を抑える工夫か、別の方法が必要です
- **閉じているときのお知らせ**：お薬・予定のお知らせは、アプリを開いているときだけです。閉じていても知らせるには、プッシュ通知などのしくみが必要です
- **何日も開いていないときのお知らせを、もっと確かに**：今は1日1回の見回りです。倒れて何も押せないときに、もっと早く気づける方法を考えます
- **データの引っ越し**：思い出はスマホの中だけに保存しているので、機種変更のときに持っていく方法が必要です
- **声**：キャラの声（読み上げ）と、歌声を聞き取って反応するしくみ
- **AI の費用**：利用者が増えたときの費用と、使いすぎを防ぐしくみ（今は月の上限を決めて守っています）
