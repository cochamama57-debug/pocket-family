# 日記の見張り役の試験結果（2026-11-05）

日記は Claude Opus 5.5 が会話から書き、そのあと裏で、見張り役（Claude Sonnet 5.5）が会話と日記を見比べます。
本人が話していないこと（出来事・気持ち・人の名前・場所・数など）が入っていたら、その部分だけを直してから画面に出します。利用者には見えません。日記の中身はどこにも残さず、件数だけ数えます。

試験の会話はすべて作り話です（`diary-cases.json`）。間違えやすい場面を12件用意しました：とても短い日、キャラの推測を本人が打ち消した、名前の出ない人、つらい日、思い出話、話が多い日、本人が認めたこと、書き足し、直しの頼み、気持ちを言っていない日、時刻と数。

## 1. Opus が書いた日記（`eval-diary.mjs`）
- 12件中、話していないことが入っていたのは1件1か所（「お花見に行っていない」→「今日は出かけずに」と広げた）。
- この1か所を見張り役が見逃したので、「〜しなかった」を広げるのも話していないことに入る、と決まりを足し、よく見るようにした。

## 2. わざと間違いを混ぜた日記（`diary-planted.json`、`eval-check.mjs`）
12件それぞれに、正しい日記と、間違いを1つ混ぜた日記を用意しました（知らない人の名前・言っていない気持ち・場所・数の変更・打ち消した出来事など）。

| | 結果 |
|---|---|
| 混ぜた間違いを見つけた | **12 / 12** |
| 混ぜた言葉を消せた | **12 / 12** |
| 直したあと、元の正しい日記と同じになった | 10 / 12（残り2件も、混ぜた言葉は消えて、話したとおりの文になった） |
| 正しい日記を、まちがって「おかしい」と言った | **0 / 12** |
| 正しい日記を、書き換えてしまった | **0 / 12** |

（最初の回では、正しい日記12件中7件で「おかしい」と知らせました。理由はすべて、試験のために付けた仮の題名「試験」が会話にないことでした。本物の題名にして試し直した結果が上の表です。）
